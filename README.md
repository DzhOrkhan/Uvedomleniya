Мини-приложение «Уведомление о прибытии»

Это готовая папка сайта. Выложите её на любой бесплатный статический хостинг
(например, GitHub Pages, Cloudflare Pages или Netlify) — получите адрес https://...
Откройте этот адрес на телефоне:
  iPhone (Safari):  «Поделиться» -> «На экран Домой»
  Android (Chrome): меню ⋮ -> «Установить приложение» / «Добавить на главный экран»
После первого запуска приложение работает без интернета.
Введённые данные хранятся только в браузере телефона и никуда не отправляются.
Папку нельзя открывать двойным кликом на iPhone: нужен именно адрес https://.
